# VerZan Check

A free page that fingerprints a file in your browser (SHA-256) so you can compare it with a fingerprint recorded earlier, plus a short demonstration of what a deleted record does to a log. Nothing you type or drop leaves the page. It sets no cookies and loads nothing from other websites.

Version 1.2.4, 6 November 2026. The whole tool is one file, `index.html`, so its source is the page itself.

What a match means: the file is byte-for-byte the one that was fingerprinted. It does not show when, by whom, or that the content is true or complete.
